# Foundry Creature AI — version 0.35.0

Version **0.35.0** adds shared condition action rules with separate [AI integration](condition-ai.md) and [manual character automation](condition-manual.md). Restrained, Immobilized, Prone, Fascinated, Sickened, Deafened, Stupefied and Synesthesia now constrain supported actions or their utility. Valued Stunned uses current action-loss rules and Workbench's existing payment when enabled; Retch uses a recorded native source DC. **Condition actions / sources** opens the recovery/source controls. Native **Step** and **Sneak** movement choices replace the movement-action popup. Existing reaction decisions remain awaited. The compatibility setting prevents duplicate Frightened reduction while preserving Workbench persistent damage and Stunned automation. Reload all clients with **Ctrl+F5** and confirm **Running code 0.35.0**. See the [rules and module audit](condition-rules-audit-2026-11-06.md) for ownership, sources and limits.

Version **0.34.0** allows Blinded NPCs to continue combat: hearing locates ordinary opponents as Hidden, targeted attacks require DC 11 flat checks, hearing Seek can locate Undetected enemies without making them Observed, and movement uses non-stacking difficult terrain. Blind defenders are off-guard to attackers they cannot precisely perceive. These shared targeting, defense and movement rules also apply to supported manual PC actions. Cover/concealment/Hidden captions now repair stale native tooltip text on movement and selection events. Reload all clients with **Ctrl+F5** and confirm **Running code 0.34.0**. See [condition handling](condition-handling.md).

Version **0.33.1** adds `macros/enable-selected-full-auto.json` (importable) and `.js` (Script command). Select NPC tokens as the active GM and run the macro to enable AI, automatic acting at turn start and automatic turn advancement. It resumes automatic starts after Stop/reset, preserves existing targeting/resources/preferences, and starts on subsequent turn-start events. Unsupported, linked or player-character tokens are reported and skipped. Neutral NPCs need saved manual targets. Reload with **Ctrl+F5** before using the new macro.

Supported manual spell saves use the same source-tracked effect resolver. The wand toolbar button opens **Ongoing spells / Sustain** for players. Other Dero spells, medicine and Confused turns remain manual. Blinded turns are supported from 0.34.0.

Version **0.32.0** separates [air-to-air tactics](aerial-combat.md) from hunting ground prey. Faster Eagles can prepare a fixed, speed-aware altitude advantage for at most three Fly actions, then engage with a complete Dive and withdrawal. Slower melee flyers can descend to cover, land and Hide when a high opponent cannot be reached efficiently. Quill Manticores can answer with ranged attacks instead of chasing altitude. Physical surfaces, native movement costs, observer-relative stealth and awaited reactions remain authoritative. Reload all clients with **Ctrl+F5** and confirm **Running code 0.32.0**.
